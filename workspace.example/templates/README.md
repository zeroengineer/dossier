Put workspace templates here: `templates/<templateId>/template.json` (plus `index.js` and/or `body.md`).
A folder whose id matches a built-in template overrides it; a new id adds a document type. An override without
`index.js` keeps the built-in code: put only `body.md` (e.g. `templates/mou/body.md`, `body.event.md`) and/or
`template.json` there.
See `docs/TEMPLATES.md` in the Dossier repository.
